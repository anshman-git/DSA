# DSA — LeetCode & GeeksforGeeks

A personal archive of my Data Structures and Algorithms practice.

Solutions are synced from accepted submissions on:

- [LeetCode](https://leetcode.com/)
- [GeeksforGeeks](https://www.geeksforgeeks.org/)

## Repository structure

The sync extension will create platform folders and organize solutions automatically. Depending on its settings, files may also be grouped by difficulty or programming language.

```text
DSA/
├── LeetCode/
└── GeeksforGeeks/
```
